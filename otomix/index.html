ポッドキャスト BGMミキサー
Podcast BGM Mixer

録った声に、BGMをのせて仕上げる

声とBGMを入れるだけで、イントロ → 本編のBGM下げ → ジングルへのつなぎまでを自動でミックスし、ポッドキャストの標準音量（−16 LUFS）にそろえた音源を書き出します。

音源はこの端末から出ません。変換はすべてブラウザの中で完結します。ファイルがどこかのサーバーに送られることはないので、未公開の収録データをそのまま入れて大丈夫です。

ダウンロード

読み込める形式：M4A / AAC（iPhone・Androidのボイスメモはこれ）MP3 WAV FLAC OGG / Opus。書き出しは M4A か WAV を選べます。MP3での書き出しには対応していません——ブラウザにMP3を作る機能が無いためです。M4Aは主要な配信サービスがそのまま受け付けます。

処理内容は podcast_bgm_mixer.py（ffmpeg版）と同じ手順を Web Audio API で組み直したものです。ラウドネスは ITU-R BS.1770-4 の K特性フィルタとゲーティングで測定し、真のピークは4倍オーバーサンプリングで求めています。
